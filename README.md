# Titanic-Survival-Prediction

## Introduction

The Titanic Survival Prediction project is a Machine Learning-based classification system developed to predict whether a passenger survived the Titanic disaster or not. The project uses historical passenger data such as age, gender, passenger class, fare, and family details to analyze survival patterns and build predictive models.

The main objective of this project is to apply Machine Learning techniques for classification, perform data preprocessing, analyze survival patterns, and evaluate model performance.

Results

The model successfully predicted passenger survival using Machine Learning classification techniques.

### Key Findings
Female passengers had higher survival rates.
First-class passengers had better survival chances.
Age and fare influenced passenger survival probability.
Accuracy Achieved
Approximately 81.5% model accuracy was obtained.
